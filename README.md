# موقع محمود الجعافرة

نسخة ثابتة قابلة للنشر من معرض أعمال محمود الجعافرة، مصمم بصري وصانع أفكار.

## التشغيل محلياً

لا توجد حزم أو عملية بناء مطلوبة. شغّل خادماً ثابتاً من مجلد المشروع:

```bash
python3 -m http.server 8000
```

ثم افتح <http://localhost:8000>.
