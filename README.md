# لعبة الحروف الإنجليزية

لعبة تعليمية عربية بسيطة للأطفال تساعد على ربط الحرف الإنجليزي الأول باسم الحيوان. يختار التطبيق حيواناً عشوائياً، ثم يجيب اللاعب بسحب الكرة إلى الحرف الصحيح أو بالنقر على الحرف مباشرة.

## التشغيل

لا توجد حزم أو عملية بناء مطلوبة. افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً من مجلد المشروع:

```bash
python3 -m http.server 8000
```

ثم افتح <http://localhost:8000>.

## ما تم إكماله وإصلاحه

- توحيد السحب للفأرة واللمس والقلم باستخدام Pointer Events، مع منع فقدان الكرة عند تحريك المؤشر خارجها.
- إضافة طريقة إجابة بديلة بالنقر على الحرف، لتعمل اللعبة أيضاً من لوحة المفاتيح والأجهزة التي لا تدعم السحب بسهولة.
- إصلاح أمثلة الحروف غير الدقيقة، وإضافة كلمة حيوان مناسبة لكل حرف من A إلى Z.
- إضافة جولات لا تكرر الحرف السابق مباشرة، وتحديث الرسائل والنقاط وحالة الإجابة الصحيحة أو الخاطئة.
- إضافة زر إعادة اللعبة، وإيقاف المؤقتات القديمة عند بدء جولة جديدة.
- تحسين تموضع الكرة عند تغيير حجم النافذة وعلى الشاشات الصغيرة، ومنع خروجها من حدود الشاشة.
- إضافة عناصر وصول أساسية، مثل التسميات، وحالات التركيز، والإعلانات الحية للنقاط والرسائل.
- إضافة دعم `prefers-reduced-motion` وتحسين التباين والاستجابة واتجاه شريط الحروف.
- تحسين رسم الألعاب النارية وتغيير حجم Canvas مع كثافة بكسلات الشاشة، مع إزالة الجسيمات بأمان.

## التحقق

يمكن التحقق من صحة JavaScript دون تثبيت أداة بناء عبر استخراج كتلة السكربت وتشغيل فحص Node.js:

```bash
python3 - <<'PY'
from pathlib import Path
import re

html = Path("index.html").read_text(encoding="utf-8")
script = re.search(r"<script>(.*?)</script>", html, re.S).group(1)
Path("/tmp/alphabet-game.js").write_text(script, encoding="utf-8")
PY
node --check /tmp/alphabet-game.js
```
